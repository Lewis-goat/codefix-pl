De'Longhi Magnifica / Dinamica Insert Grounds Container / Empty Grounds Container: pojemnik na fusy niewykryty

Insert Grounds Container / Empty Grounds Container oznacza: Nie wykryto pojemnika na fusy albo komunikat o opróżnieniu nie znika.

Szybka odpowiedź. Pojemnik jest wykrywany przez wyłącznik lub styki znajdujące się za nim. Mokre fusy, osad z kawy lub kamień na tych stykach albo pojemnik niedosunięty do końca powodują błędny odczyt. Licznik opróżniania fusów resetuje się dopiero wtedy, gdy maszyna przez kilka sekund widzi wyjęty pojemnik.

Jak naprawić Insert Grounds Container / Empty Grounds Container

  1. Wyłącz maszynę. Wyjmij tacę ociekową razem z pojemnikiem na fusy.
  2. Wyczyść pojemnik i przestrzeń za nim, a metalowe styki lub wyłącznik przetrzyj suchą szmatką.
  3. Pozostaw pojemnik wyjęty co najmniej dziesięć sekund (aby zresetować licznik), a następnie mocno go zamontuj.
  4. Jeśli komunikat nie znika, wyłącznik uległ awarii; to tania część, ale znajduje się wewnątrz maszyny.

Nic groźnego.
